Highly recommended: A powerful interactive language learning extension for YouTube and Bilibili. This tool is a game-changer for language learners, making video-based learning effortless and engaging.

It features five distinct interactive modes:

1. Typing Mode: Automatically plays the video segment once you type the sentence correctly.

2. Selection Mode: Practice by choosing the correct words.

3. Dictation Mode: Test your listening skills by writing out what you hear.

4. Voice Input Mode: Practice your speaking and pronunciation in real-time.

5. AI Fill-in-the-Blank: Customize the difficulty level with smart, AI-generated exercises.

The extension is completely free. You can find it by searching for LangKey in the Edge, Chrome, or Firefox Add-on stores.
